# Fllooat コンセプト

MVP を作って触ってみたら、伝わりにくいところが 3 つ見つかりました。この文書には、[旧コンセプト](concept.md) から変えることだけを書きます。ここに書いていないことは旧コンセプトのとおりです。

## 課題

1. 気球がなぜその高さにいるのか分からない。重さが見た目から伝わらない。
2. 重さのあるタスクを乗せている感じがしない。自分で気球におもりを足している体験が薄い。
3. 最終更新からの経過時間で大きさと濃さを変える表現が伝わりにくい。濃さはほかの色とまぎれ、大きさは重さと取り違えられる。

課題 1 は自分とほかの人の気球が並ぶ空の画面、課題 2 はタスク編集画面で解きます。画面ごとに操作が分かれているので、2 つの解決方法は混ざりません。

## 空の画面: 籠の大きさで重さを見せる

- 気球の大きさは全員同じにする。乗っているタスクの重さの合計が大きいほど、籠を大きくする。
- 気球の高さは、旧コンセプトと同じく重さの合計で決まる。
- 操作は横スクロールと、気球を揺らすことだけにする。

## タスク編集画面: ブロックを気球にドロップする

旧コンセプトのステータス設定のポップアップをやめ、タスク編集画面に置き換えます。

- 画面下の「タスクをのせる」ボタンがあるセクションが上に伸び、画面の 9 割ほどを覆う。背景は青のべた塗りにする。
- 実装には shadcn/ui の Drawer を `direction="bottom"` で使う。上部につまみを置き、X のモバイルアプリのアプリ内ブラウザーのように、つまみを下に引くと閉じる。
- 画面の中に自分の気球を大きく描く。タスクはブロックで表し、プールから気球へドラッグ&ドロップして乗せる。
- この画面での操作はドラッグ&ドロップにする。横スクロールはしない。
- 見た目はデザイナーから画像が届いてから実装する。

### プール

まだ気球に乗せないブロックを置いておく場所です。旧コンセプトにあった「過去に落としたタスクの一覧」とピン留めはなくし、プールはこの置き場としてだけ使います。

プールを作る理由は 2 つあります。

- 今メモしておきたいが、すぐには取りかかれないタスクを置いておくため。
- タスクを乗せる操作を、気球へのドロップに統一するため。

新しいタスクは、まずプールにブロックとして作ります。

プールは「あとでやろう」と思ったタスクを書き出して置いておくだけの場所にします。

- プールのブロックは消せる。
- ブロックの編集 (タイトルや重さを直す) は MVP では作らない。直したいときは消して作り直す。
- 気球から振り落としたタスクはプールに戻さず、消す。

## 振り落とし

- スマホを振ると、空の画面でもタスク編集画面でもタスクが落ちる。
- タスク編集画面で落とすと、裏にある空の画面の気球も同じように落ちる。気球の状態は、どの画面でも同じでなければならない。編集画面で 0% になったのに、閉じたら気球が 0% の位置にいないとおかしい。

## 離れている人をグレースケールで示す

旧コンセプトの「経過時間による遠近」は廃止します。代わりに、その人が Fllooat から離れていることを見せます。

- 最後に画面を開いていた時刻から一定の時間が過ぎた人は、気球とアイコンをグレースケールにする。大きさと濃さは変えない。
- しきい値は環境変数で変えられるようにする。初期値は 3 時間。根拠はまだ詰めていないので、使ってみて 1 時間のほうがよければ変える。
- 最後に画面を開いていた時刻は、ルームの情報を数秒ごとに再取得するたびにサーバーで更新する。タブを裏に回すと再取得が止まるので、離れた時刻が残る。

## 振る操作の許可

- iPhone では、ルームに入ったら、モーションセンサーの使用を許可するボタンを出す。iOS の許可のダイアログはタップからしか開けないので、ボタンを押してもらう。
- Android と PC では許可が要らないので、ボタンは出さない。
- 許可されなかった人に、ドラッグでも揺らせると知らせる案内は作らない。本格的に運用するときに、チュートリアルとして作る。

## メニュー

ルームの画面に、ログアウト、ルームの変更、今のルーム ID の表示を置きます。配置はデザイナーの案が届いてから決めます。

## やらないこと

- ログイン画面とルーム入室画面のデザインの変更。別のエンジニアが担当している
- 落としたタスクの履歴と、よく使うタスクのピン留め
